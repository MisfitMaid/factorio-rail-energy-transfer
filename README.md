# Rail Energy Transfer

Rail supports now include integrated electric cabling, for transferring energy across oceans (f.ex on Fulgora). They have no supply range but adequate connection length (equal to 2x support's max rail length).

## Limitations and To-Dos

* Option to apply to all rails, not just supports (This is functional, but I'd like to have it behind a setting toggle for balance purposes)
* Option to apply to elevated rail ramps (Also functional, but it looks like garbage and has to have a ludicrously high wire reach. Perhaps offsetting the virtual pole to the high end of the ramp?)
* Support poles currently don't show up on the map's electric grid visualizer. They are functional however so whatevs.
* Add functionality for adding mod midgame (currently, all supports will need to be re-placed to create the virtual poles)
* Proper graphics/wire attach points
* Adjust recipe? Adding a couple copper cable would make it more sensible but also that sounds annoying as hell tbh.
